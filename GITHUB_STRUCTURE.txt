----------------------------------------------------------------
3. QUICK GIT COMMANDS
----------------------------------------------------------------

  -- Clone the repo --
  git clone https://https://github.com/tonypaponpatch/SDEV220_Final_Project_Group1.git
    cd SDEV220_Final_Project_Group1

  -- First commit (if starting fresh) --
  git init
  git add .
  git commit -m "initial commit"
  git push -u origin main

  -- Daily workflow --
  git pull                        # get latest from teammates
  git add .
  git commit -m "your message"
  git push


----------------------------------------------------------------
4. WHAT NOT TO COMMIT
----------------------------------------------------------------

  instance/thai_diner.db    Database file — each teammate runs init-db locally
  venv/                     Virtual environment — too large, not needed
  .env                      Secret keys — never commit these
  static/img/               Food photos — add to .gitignore if large


----------------------------------------------------------------
5. SETUP AFTER CLONING
----------------------------------------------------------------

  1. pip install flask flask-sqlalchemy flask-login werkzeug qrcode
  2. flask --app app init-db
  3. flask --app app run --debug
  4. Open http://127.0.0.1:5000
